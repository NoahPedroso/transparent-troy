# Alert Parser

Title: WIP
A secondary feature to be provided on Transparent Troy to allow users to filter Troy NY Road Closure Alerts (texts or email) to only those affecting a particular region.

Gazetteer formed through [NYS Street data](https://data.gis.ny.gov/maps/7d5dff6bcf664e6f83abee9968fc7916/about), filtered VERY ROUGHLY to include troy and the surrounding region. Due to file size and parsing, more accurate filtering may be desireable in the future.
