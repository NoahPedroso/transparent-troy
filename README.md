#Transparent Troy
## A website to bolster civic engaement in Troy.

### Uses
This currently only has one use: Find your city council member and info. Basically a prettier, more user friendly version of [the official city council page](https://www.troyny.gov/315/City-Council).

### Future Uses
- Find your polling place
- Any other map data
- Personal blog about troy
- Guest articles from Trojans about civic engagemnet or what is happening in the city
