# Data Sources
## Overview
This document provides some context for each of the data sources used in this project. Each data source should have (at least) the following information:
### Source
Where did the data come from? Ideally a link. Sometimes the data was massaged or trimmed from the link. If so, provide a script that did the trimming, or a description of what was trimmed, how, and why the trimmed data couldn't be organically sourced.
e.g. URL: https://example.com/data
This url gives a zip file with data for other examples, but I only needed example 1. I manually removed all other examples from the provided file.
e.g. This is data sourced from Trojans via word of mouth. This is the authoritative compiled data source, handmade.

### Update Frequency
Does it automatically update? Do you need to check to see if data changed periodically? Is there an event that triggers a manual update? If it is just updated as you see fit, when was the last time you updated it?
